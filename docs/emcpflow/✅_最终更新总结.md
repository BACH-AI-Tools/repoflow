### 问题1: 路由前缀格式限制 ✅

**需求**：
- 只能由小写字母(a-z)和数字(0-9)组成
- 不能以数字开头
- 长度不超过10个字符

**解决方案**：

实现了 `_normalize_route_prefix()` 方法：

```python
def _normalize_route_prefix(route_prefix: str) -> str:
    # 1. 移除所有非字母数字字符
    route_prefix = re.sub(r'[^a-z0-9]', '', route_prefix.lower())
    
    # 2. 如果以数字开头，添加'mcp'前缀
    if route_prefix and route_prefix[0].isdigit():
        route_prefix = 'mcp' + route_prefix
    
    # 3. 限制长度不超过10个字符
    if len(route_prefix) > 10:
        route_prefix = route_prefix[:10]
    
    return route_prefix
```

**测试结果**：
```

web_parser         → webparser    ✅ (移除下划线)

✅ 所有14个测试用例通过！
```

### 问题2: template_source_id 使用 bach-001 ✅

**需求**：
- template_source_id 写 "bach-001"
- 每次调用都选择带 bach 的来源

**解决方案**：

#### 方法1: 动态获取（已实现）

```python
def get_bach_template_source_id() -> str:
    """获取包含'bach'的模板来源ID"""
    sources = get_all_template_sources()
    
    for source in sources:
        source_id = source.get('template_source_id', '')
        source_name = source.get('template_source_name', '')
        
        if 'bach' in source_id.lower() or 'bach' in source_name.lower():
            return source_id  # 返回实际的 bach-xxx
    
    return 'bach-001'  # 默认值
```

**调用API**：
```
GET https://sit-emcp.kaleido.guru/api/TemplateSource/get_all_template_source
```

**自动选择**：
- 自动查找名称或ID包含"bach"的来源
- 找到后使用该ID
- 找不到时使用默认值 "bach-001"

#### 方法2: 固定使用（备选）

```python

```

**当前实现**：使用方法1（动态获取），更灵活可靠
